A one-sentence pitch for the Parachute Toaster: a toaster that launches every
slice with a tiny parachute, so your toast drifts gently down to the plate
instead of landing butter-side down — a ridiculous machine fixing the tiny,
universal annoyance of toast that always seems to land face-down on the
floor.

Running `python3 main.py` writes the single 143-character sentence to
`/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
